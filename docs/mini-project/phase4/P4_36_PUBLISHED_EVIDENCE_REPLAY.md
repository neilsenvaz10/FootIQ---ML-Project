# Phase 4.36: legally reproducible current-state replay

No Git staging, commit, push or LFS setup; no history rewrite; production data, frozen models and running services untouched (production hash `5f38b226...` before, during and after; every replay and test used private copies). Everything is done and verified (full backend regression in section 6).

## 1. Importer changes
- New module `app/store/published_evidence.py`: allowed sources (Wikipedia CC BY-SA 4.0, openfootball CC0, OpenLigaDB ODbL), the published schema, and the rule. A published file with **any restricted-provider column is refused as a whole**; a result needs the same score from at least two distinct allowed sources, a played day or corrected date the same date from at least two; a classification label that contradicts the recorded values rejects the row.
- `league_results_import.py` and `reconcile_import.py`: new `--evidence {restricted,published}` option (default **restricted**, behaviour unchanged: the 68 existing importer tests pass unmodified) and `validate_published`, which keeps every other row check and replaces only the source rule. Provider-assisted changes cannot exist in published mode. Provenance and `sync_runs` text say "published evidence". Before-copies: `data/supervised/phase4/p436/before/`.
- `scripts/rebuild_current_state.py <folder> [published|local]` (default published), `scripts/build_published_evidence.py`, `scripts/list_unreproducible_records.py`.

## 2. Published-evidence dataset manifest (`data/evidence/published/`)
`published_evidence_2026-10-28.csv` (175 rows: 71 domestic results, 104 reconciliation proposals; SHA-256 in `PUBLISHED_EVIDENCE_MANIFEST.json`), `NOT_REPRODUCIBLE_FROM_PUBLISHED_EVIDENCE.csv` (114 records, no scores), `README.md`. Per record: competition, season, teams, date, result, Wikipedia revision and score, OpenLigaDB score/date/match id, openfootball date, production decision and tier, evidence classification, confidence, uncertainty, licence, provenance, and `restricted_cross_check_used_in_production` (a flag, no value). No football-data.co.uk, FixtureDownload or football-data.org value or column appears (scanned; a test enforces it). **All 175 records are classified `insufficient_redistributable_evidence`**: the second source of every decision was restricted. I checked the alternatives: openfootball upstream's results end on 20 Sep 2026 (read today), OpenLigaDB has only Bundesliga, La Liga and a lagging Premier League feed (5 of the 6 La Liga results have its score but only one date source), Wikipedia's league grids carry no per-match dates.
